# 更新日志 / Changelog

版本遵循 semver；1.0 之前，**破坏性变更升次版本号**。

## 0.2.0

### ⚠️ 行为变更（升级前请确认）

- **相对时长倒计时改走单调钟。** `countdown(60000, …)` 这类相对时长不再受系统改时间影响（前跳 / 回拨都不动它）。绝对 `Date` / 时间戳 / 日期字符串、自定义 `dateParser` 仍跟随墙钟。
  `pause()` → `resume()` 之后任务一律按单调钟继续。_迁移：_ 若你依赖相对倒计时跟随系统时间，请改传绝对 `deadline`。
- **新增 `muteHidden`，默认 `true`。** 页面隐藏或元素离开视口时，任务跳过 `render` / `onUpdate`；进度与完成仍按真实时间推进，`onDone` 照常触发，重新可见时立即刷新为当前值。
  没有 `el` 的 count-up 任务不静音。_迁移：_ 若你在离屏 / 后台依赖 `onUpdate` 做业务逻辑，给任务（或分组 / 全局默认）传 `muteHidden: false`。
- **`ctx.deadline` 恒为墙钟时间戳。** 相对时长任务的 `ctx.deadline` 是按当前剩余推算出的墙钟值（暂停恢复后随之更新）。

### 新增

- **休眠调度。** 插件 `install(now, dt)` 可返回正数毫秒（"至少这么久之后再叫我"）。所有忙碌插件都返回数字时核心不逐帧空转，只挂一个定时器休眠；新增 / 恢复 / 移除任务会唤醒它。
  同一时刻批量创建的整秒倒计时由每秒 60 帧降到约 1 帧。
- **后台标签页准时完成。** 页面隐藏时 rAF 会停摆，核心改用定时器驱动，倒计时的 `onDone` 不再拖到用户切回来才触发（受浏览器对隐藏页定时器的节流限制）。
- **`fps`（count-down）。** 仅对 `showMilliseconds` 任务限制显示频率（按固定网格、半个 vsync 容差，不补发错过的帧），完成不受限帧影响。
- 系统休眠补偿：隐藏期间墙钟比单调钟多走超过 1 秒的部分，在恢复可见时补回单调钟。

### 修复

- 任务回调（`render` / `onUpdate` / `onDone` 等）抛错不再饿死同组其余任务；`onDone` 抛错也不会让任务留在队列里逐帧重复触发。`render` 抛错不再吞掉 `onDone`。
- tick 过程中新增任务（如在 `onDone` 里新建）不再因为先跑的插件已报空闲而丢帧。
- 休眠期间移除 / 清空最后一个任务后，不再留下一个空等的定时器。

### 内部

- 单测覆盖率 100%（语句 / 分支 / 函数 / 行）；`vitest.config.ts` 的假时钟同时接管 `performance`。
- 新增前后对比基准 `scripts/bench/`（真实无头 Chrome，base/cur 交错测量），见其 README。
- 源码 lint 0 error，`oxfmt` 全仓通过。
