## 3. 终审期间主会话的修复

1. **不写泛型时 `createAxp({ plugins: [axpRetry()] })` 编译失败**（9324bfb）。R 被 `plugins` 反推成 `IAxpResponse`，进而要求必填 `response`；单独定义的插件默认也是 `IAxpResponse`，装不进默认客户端，README 的写法会踩到。改为 `plugins`、`reject` 用 `NoInfer`，R 只由显式泛型或 `response` 工厂决定；十个插件工厂默认泛型改为 `AxpResponse`。类型测试覆盖内联、单独定义、只给工厂三种写法，两个改动各做了变异验证。取舍：只给 `response` 工厂、内联插件又不写泛型时会报错，要写 `createAxp<S, MyResponse>`；比起让 R 悄悄退回 `AxpResponse` 丢掉自定义字段，报错更安全，也符合设计文档"自定义 R 写显式泛型"。
2. **格式与 lint 口径**（901a336）。B1–B5 一直用不带 `-c` 的 `vp check`，走默认规则：printWidth 100、不开类型感知 lint。项目真正的标准是 `npm run check`（printWidth 220、typeAware lint）。整仓按 `npm run fmt` 重排一次（只有格式变化）；新增 `apps/axp/.gitattributes`（`eol=lf`），Windows 检出不再是 CRLF。按项目 lint 配置跑，`src`、`test`、`bench` 还有约 50 个 error，已单独派任务清理。
