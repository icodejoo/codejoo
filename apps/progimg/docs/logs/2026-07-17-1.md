# 2026-07-17-1: 项目改名 picman → imgprogress

## 变更原因

项目原名 `picman` 不够直观，无法清晰表达核心功能（渐进式图片加载）。改名为 `imgprogress` 更能准确传达产品定位，便于使用者快速理解功能价值。

## 目的

提升项目名的通俗性和搜索友好性，使功能意图在包名中一目了然。

## 落地方案

### 包名与导出

- Package name: `@codejoo/picman` → `@codejoo/imgprogress`
- 导出路径同步更新: `./sw` / `./element` / `./shared` 保持不变

### API 名称统一

主要受影响的 API（其余内部类型/常量同步）：

| 旧名                      | 新名                       |
| ------------------------- | -------------------------- |
| `registerPicmanSW()`      | `registerImgprogressSW()`  |
| `setupPicman()`           | `setupImgprogress()`       |
| `PicmanTask`              | `ImgprogressTask`          |
| `PicmanAutoOptions`       | `ImgprogressAutoOptions`   |
| `ImgprogressErrorContext` | `ImgprogressErrorContext`  |
| `PicmanSWOptions`         | `ImgprogressSWOptions`     |
| `<pic-man>` 元素          | `<img-progress>` 元素      |
| `data-picman-bg` 属性     | `data-imgprogress-bg` 属性 |

### 构建产物

- SW 独立入口: `dist/picman-sw.js` → `dist/imgprogress-sw.js`
- 缓存桶名: `"picman-v1"` → `"imgprogress-v1"`
- 构建环境变量: `PICMAN_BUILD_SW` → `IMGPROGRESS_BUILD_SW`

### 文档更新

- README.md: 包名、代码示例、属性名全部更新
- ARCHITECTURE.md: 示例代码、缓存名同步
- CHANGELOG.md: 记录本次改名
- 生成的协议常量: `X-Picman` → `X-Imgprogress`、`__picman_*` → `__imgprogress_*`

### 版本号

本次改名作为 0.2.0 的一部分同步发布。由于 npm 包名变更，旧用户需重新安装新包名。

## 相关文件修改

- src/\*_/_.ts: 所有导出 API、类型、常量
- package.json: 包名和导出路径
- vite.config.ts: 构建入口名
- scripts/build.mjs: 构建脚本环境变量
- README/ARCHITECTURE/CHANGELOG: 文档示例

## 注意事项

- 这是一次**破坏性改名**（breaking change）：现有用户需更新代码引入新包名
- 旧包名 `@codejoo/picman` 停止维护，建议迁移至 `@codejoo/imgprogress`
