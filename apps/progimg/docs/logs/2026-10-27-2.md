# 2026-10-27-2: 第二轮全量 code review(Codex)修复

## 变更原因

第一轮修复(2026-10-27-1)之后,Codex 对 `@codejoo/imgprogress` 又做了一轮全量 review,经终审确认一批成立的问题:页面端阶段回调异常会拖垮 `load()`、first-frame 在 complete 之后发出、`auto()` 在属性失效/换 URL/stop 后的状态残留与错写、视频接管的 autoplay/源改写/play 补丁清理、SW 管线对 no-store 与无 Content-Length 小动图的处理、隔行 PNG 与非整画布 WebP 的边界,以及若干测试 mock 过于宽松、examples 演示有失真。

## 目的

- 页面端各状态机在异常回调、属性被移除、换 URL、stop 之后行为正确,不泄漏状态、不错写元素。
- SW 管线与缓存对 no-store、无 Content-Length、失败遗留 ff 条目的处理符合预期。
- 嗅探层不把"还解不出全图预览"的隔行 PNG、也不把非整画布的 WebP 首帧当成可显示的首帧。
- 测试更贴近真实语义,能真正区分被测行为;examples 演示与实现一致。
- 不改公共 API 签名,不引入新依赖。

## 落地方案

### 页面端

- `load.ts`:`emit` 逐个回调 try/catch,异常用 `queueMicrotask` 异步重抛;新增 `completeEmitted`(complete 的 idle 回调里置位),`emitFirstFrameOnce` 见其已置位即丢弃;改正"scheduleIdle 先进先出"的错误注释。
- `element/index.ts`:补齐 `observedAttributes` 与各生命周期回调的注释;`startLoad` 无论 src 是否为空都先自增 generation,空 src 时清掉内部图的 src;`defineImgProgress` 用匿名子类注册。
- `auto.ts`:新增 `imgSrc` helper 按 `getAttribute("src")` 判空(scan/addedNodes/属性变更共用);`track` 换 URL 时清 `elExpected`;属性变更先判 `root.contains(el)`,不在 root 内的记录先 `releaseElement` 再跳过(背景元素同批移出并删属性时 untrackSubtree 筛不到它);`isOwnEcho` 的 URL 状态回退要求 `elUrl.get(el) === canonicalize(rawUrl)`;拆出无条件的 `releaseElement`,src / `data-imgprogress-bg` 失效时调用;`untrackElement` 守卫改 `root.contains(el)`;`applyStageWhenIdle` 的 idle 回调检查 `stopped` 与 `tracked.has(url)`。
- `viewport.ts`:`inViewport` 增加横向判定。
- `video.ts`:`restore` 仅在 `play || videoAutoplay !== false` 时恢复 autoplay;写回源时优先用元素当前的 `src`/`<source>`;`restore` 遍历元素当前的 `<source>`(有 src 的套播放标记,快照中仍在且无 src 的回填);意图监听共用 `AbortController`,还原时 abort 并还原 `play`(原无 own 属性则 delete);after-lcp 无 IntersectionObserver 时直接放行。
- `protocol.ts`:`isImgprogressMessage` 校验 `url` 与 `type`,error 消息再要求 `message` 为字符串、`stage` 为 download/first-frame。

### SW 与 shared

- `cache.ts`:`putStage` 任意阶段写入后都登记 LRU 索引并按上限淘汰;只有全图写入或该 URL 尚无条目才写时间戳(ff 不刷新);索引登记段 try/catch,失败不影响返回 true。
- `pipeline.ts`:新增 `hasNoStore`,no-store 响应直接透传;无 Content-Length 时交接条件需累计到 threshold;catch 兜底回落用去标记 URL。
- `sniff.ts`/`walkers/apng.ts`:`scanPng` 额外解出 bitDepth/colorType;新增 `adam7Pass1Bytes`,隔行 PNG 可显示门槛取 `max(4096, 第 1 遍原始字节 + deflate 余量)`。
- `walkers/webp.ts`:`webpFirstFrame` 在帧偏移非 0 或帧尺寸 ≠ 画布时返回 null。

### 测试

- 新增 `viewport.test.ts`;`load/element/auto/video/protocol/cache/pipeline/sniff/webp/register/avif` 各补对应用例。
- `fixtures.ts`:APNG 的 fcTL 带有效尺寸与序号并补第二个 fcTL;`makeJpeg` 增 `tailBytes`、`makeBigPng` 增宽高、`makeWebp` 增帧偏移/帧宽。
- `cache.test.ts` 的 Cache mock 改为 put 消费 body、match 每次返回新 Response;`video.test.ts` mock 原生 play 并在 afterEach 恢复全局改写。

### examples(不进包)

- `serve.ts`:后缀 Range、非法 URL 回 400、统一异常处理、限速分支处理背压与断连、按实际 chunk 字节数算等待时长;背压等待用 `AbortController` 让 drain/close 竞速后清理输家监听。
- `index.html`:展示层 img 放进 shadow root,避免被 `auto()` 接管而绕过延迟;改正 D 节关于缩略图来源的说明。
