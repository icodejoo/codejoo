# 2026-10-27-1: 全量 code review 修复

## 变更原因

对 `@codejoo/imgprogress` 做了一次全量 code review,逐条核实后确认一批成立的问题:SW 缓存的配额重试与并发索引写入会丢数据、页面端订阅/重试/换 URL 存在状态错乱、shared 层 walker 与 URL 工具有边界缺陷、构建与发布配置(`sideEffects`、`prepublishOnly`)会让产物行为不符预期、examples 还停留在旧名 `picman`。这些问题分散在各模块,统一一轮修掉。

## 目的

- 让缓存、管线、页面端状态机在异常路径(配额失败、重复通知、换 URL、通知失败、无响应的 `ready`)下行为正确、不丢数据、不悬挂。
- 发给源站的 URL 不被改写,公共协议常量只有一处出处。
- 发布产物与包声明一致,examples 可直接运行。
- 不改公共 API 签名,不引入新依赖;调色板链路、`PARAM_THUMB_SCALE`、`deleteUrl`、`sw/placeholder.ts` 的 re-export 等在建/遗留项保持不动。

## 落地方案

### shared
- `protocol.ts`:标记参数提为常量数组;`stripImgprogressParams`/`withStageParam`/`withPlayParam` 直接在原始 query 字符串上增删标记参数(内部 `rewriteQuery`),不再经 `URLSearchParams` 重写其余参数,保证 `strip(withStage(x)) === new URL(x).href`;无标记时 `stripImgprogressParams` 原样返回;新增 `DEFAULT_SKE_COLOR`,`types.ts`/`auto.ts`/`video.ts` 改引用。
- `placeholder.ts`:新增 `normalizeHexColor`,`adjustHexBrightness` 非法输入原样返回。
- `walkers/gif.ts`:第 2 个图像描述符出现即判 animated;`walkers/apng.ts`:首个 IDAT 块头即定 status,fourcc/拼接复用 `readFourCC`/`concatBytes`;`walkers/jpeg.ts`:仅渐进式扫 scan 结束位置;`walkers/webp.ts`:fourcc 复用 `readFourCC`,合并重复分支。
- `shared.ts`:补文件头注释。

### SW 端
- `cache.ts`:`putStage` 首次写入用 clone;新增 `withIndexLock` 串行化索引读改写(matchStage 触碰、putStage 写索引与淘汰、配额淘汰、deleteUrl);`matchStage("1")` 只读一次索引。
- `pipeline.ts`:`concatStream.cancel`;`completeDownload`/`failDownload`/`placeholderResponse`/`passthroughResponse`/`responseInitOf` 抽取复用;新增 `reportError` 包住用户 `onError`,钩子抛错不影响通知与降级;ff 写失败不通知;动图无宽高/超上限无结论时透传;透传保留 status;回落请求用 `new Request(strip, request)`;`PARAM_FULL` 无效值直接回落;`request.destination` 直接取;正则 `lastIndex` 重置;`PARAM_SKE` 过 `normalizeHexColor`,色块缓存加上限。
- `placeholder.ts`:`makeFirstFramePlaceholder` 全路径兜底返回 null,`bitmap.close()` 进 finally,缩放尺寸至少 1px。

### 页面端
- `messages.ts`:退订幂等,仅在登记表仍是自己那份集合时才移除。
- `load.ts`:canonical 剥标记参数;`completeScheduled` 标志实现 complete 只处理一次,并丢弃其后到达的 first-frame/error(`scheduleIdle` 先进先出,complete 调度前已排队的 first-frame 本就先于它发出)。
- `auto.ts`:`retryAll` 用 `setDisplay`;`track` 换 URL 时先从旧集合摘除(`removeFromUrlSet`,与 `untrackElement` 共用)、同 URL 不重复加 WeakRef;背景图 `url("...")` 加引号并转义;JSDoc 归位;`onMessage` 显式 `else if`。
- 新建 `viewport.ts` 导出 `inViewport`,auto/video 共用。
- `register.ts`:`ready` 用 `Promise.race` 加 10s 超时,超时视为未控制继续启动 `auto()`。
- `video.ts`:抓首帧仅接受 206 并取消多余 body;`waitFirstFrame` 加 10s 超时并摘除监听;`track`/`stop` 补注释。
- `types.ts`:`offViewport: 'placeholder'` 文档改为与实现一致。

### 构建与示例
- `package.json`:`sideEffects` 列出 element 入口,`./sw`/`./element`/`./shared` 补 `default` 条件,`prepublishOnly` 改为 `pnpm run check && pnpm run build`。
- `examples/`:`sw.ts`/`index.html`/`serve.ts` 同步新名;`serve.ts` 加路径穿越防护(400/403)。

### 测试
新增/调整用例覆盖上述各条;`video.test.ts` 既有抓帧用例的 fetch mock 补 `status: 206` 以符合 Range 语义。
